## 4. Gotchas a new session must know

- Testing `claude -p` from inside a Claude Code session: the session exports `ANTHROPIC_BASE_URL=https://api.anthropic.com` and `ANTHROPIC_AUTH_TOKEN` to children, which override `settings.json`. Use `env -u ANTHROPIC_BASE_URL -u ANTHROPIC_AUTH_TOKEN -u ANTHROPIC_MODEL claude -p …`.
- The seat's Codex omniroute provider table reads `OPENAI_API_KEY`; the login shell does not export it. Native ChatGPT login is the default; the gateway is per-run via `codex -c 'model_provider="omniroute"' -m <combo>`. Do not set a top-level `model_provider` on the seat unless that variable is exported.
- The PAI security hook blocks `source`-ing env files in shell commands. Use plain `export` lines or pass values inline.
- The login Keychain cannot be written over SSH (no GUI session). On the Coding Mac the gateway key lives in `~/.config/snowgloves/gateway.key` (600) and `~/.zshenv` exports it. Replace with a scoped key, and with Keychain from a Screen Sharing session.
- Changing `OMNIROUTE_SERVER_HOST` needs `launchctl bootout` + `bootstrap`; `kickstart -k` keeps the old environment. The first bootstrap may return error 5 until `launchctl enable gui/<uid>/<label>` is run.
- OmniRoute binds a single address: on the Coding Mac loopback is refused; on-host tools must use the tailnet address. The Temperance fleet sync script only addresses loopback.
- `omniroute sync bundle` returned 401 on the seat (CLI key lacks the management scope; same root cause as the MCP 403). Fix per `~/.temperance_engine/docs/operations/omniroute-mcp-key-rotation.md` before relying on route B.
- `git bundle` of this repo fails (shallow history at `3353e52`); use rsync or an incremental push.
- macOS has no `timeout`; use `perl -e 'alarm N; exec @ARGV' -- cmd`. Programs that read stdin (Claude Code, Codex) will eat a `bash -s` script over SSH unless given `</dev/null`.
- Temperance hardwires `127.0.0.1:20128` in about 70 scripts; any design that removes the seat's loopback gateway must keep a listener on that port (the socat forwarder did).
