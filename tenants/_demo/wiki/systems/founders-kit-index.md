# founders-kit reference catalog

MIT directory of startup tools and playbooks — **not** Snow Gloves agent skills.

| Item | Location |
|------|----------|
| Vendor tree | `vendors/founders-kit/` (git submodule) |
| Pinned commit | `vendors/founders-kit.pin` |
| Ingest files | `README.md`, `Product.md`, `PRODUCT_SUBMISSION.md` |

## How we use this

- Librarian retrieval and Chief-of-Staff browsing only.
- Complements vault discovery-log ecosystem rows; does **not** replace `AGENTS.md` seven-agent model.
- Do not register hooks in `workflows/skill-hooks.yaml` without a separate Four-Signal founder pick.
- Do not run `npx skills` or auto-install from this catalog.
